# راهنمای تستر Loomi

## ورود

لینک فضای کار، نام‌کاربری و یک رمز اول را از مالک فضای کار می‌گیرید. با همین‌ها وارد شوید.

## تغییر رمز

همان اولین بار که وارد شدید، رمزی که مالک به شما داده را عوض کنید: **Settings → Change password**. رمز فعلی و یک رمز جدید (حداقل ۸ نویسه) بدهید. بعد از این، حتی مالک هم رمز شما را نمی‌بیند.

## ساخت پروژه

**New image project** را بزنید و یک عنوان بدهید. هر پروژه یک گفتگوی اختصاصی با ChatGPT است؛ همه‌ی نسخه‌ها و شاخه‌های آن پروژه کنار هم و زیر همان یک عنوان می‌مانند.

## ارسال درخواست، با تصویر مرجع در صورت نیاز

داخل پروژه، توضیح تصویری که می‌خواهید را در کادر پایین بنویسید. با دکمه‌ی **Attach** می‌توانید تا ۴ تصویر مرجع (PNG، JPEG یا WebP، هرکدام حداکثر ۲۰ مگابایت) پیوست کنید تا ساخت روی آن‌ها مبتنی باشد. سپس **Generate** را بزنید (یا کلیدهای Ctrl/Cmd + Enter).

- **Edit** روی یک تصویر قبلی، همان گفتگو را ادامه می‌دهد و آن تصویر را دوباره به‌عنوان مرجع می‌فرستد — برای اصلاح همان چیزی که ساخته شده.
- **Branch** یک گفتگوی تازه از همان تصویر می‌سازد تا مسیر متفاوتی را امتحان کنید بدون اینکه نسخه‌ی قبلی را از دست بدهید.

## وضعیت‌ها یعنی چه

| وضعیت | یعنی چه |
|---|---|
| Queued | در صف، منتظر نوبت |
| Opening browser / Opening ChatGPT | مرورگر یا صفحه‌ی چت باز می‌شود |
| Sending prompt / Waiting for response / Generating image / Downloading image | مراحل پشت‌صحنه‌ی همان یک درخواست، به ترتیب |
| Completed | تمام شد؛ تصویر ذخیره است |
| Failed | ناموفق بود — پیام خطا کنارش نشان داده می‌شود |
| Cancelled | خودتان یا مالک آن را لغو کرده‌اید |

## اعتبار (Credits)

هر ساخت، ویرایش یا شاخه‌ی تازه یک هزینه‌ی ثابت از اعتبار شما کم می‌کند (رقم را مالک تنظیم می‌کند). اگر نتیجه **Failed** یا **Cancelled** شود، همان اعتبار خودش برمی‌گردد — یعنی فقط برای کاری که واقعاً تصویر تحویل داده هزینه می‌دهید. اگر اعتبار کافی نداشته باشید، پیش از ارسال به شما گفته می‌شود.

## وقتی چیزی درست پیش نرفت

قبل از ارسال دوباره، وضعیت اتصال را بالای صفحه یا از Settings → Connection ببینید؛ اگر Connected نیست، صبر کنید تا مالک وصلش کند — ارسال در آن حالت راه به جایی نمی‌برد.

اگر با وجود Connected بودن هم مشکلی دیدید، این‌ها را برای مالک بفرستید (رمزتان را **هرگز**، حتی اگر بپرسند):

- ساعت تقریبی
- نام پروژه
- متن دقیق درخواستی که فرستادید، و اینکه تصویر مرجعی پیوست بود یا نه
- چه چیزی روی صفحه دیدید — پیام خطا، یا اینکه روی کدام وضعیت متوقف ماند
