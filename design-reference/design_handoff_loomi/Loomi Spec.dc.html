Status is never carried by hue alone: every status pairs a color with a glyph (✓ ◐ ! ◔) and a written label, so the tree stays readable for color-blind users and in grayscale print. Body text holds ≥ 4.5:1 on every surface; the steel accent is used at ≥ 3:1 for chrome and large type only.

Stores (Pinia)
useProjectsStore · useGenerationStore · useConnectionStore · useUiStore (lang, theme, view, sidebar)
Realtime
A SignalR hub pushes generation state transitions (connecting → sending → waiting → generating → downloading → completed|failed) so every card, the composer bar and the sidebar dot read one source of truth.
i18n & direction
vue-i18n with en.json / fa.json; a useDirection() composable writes dir and data-lang on <html>. Components never read left/right — only logical properties.
